🌌 Titan AI StudioTitan AI Studio is a high-performance, multi-language ecosystem designed for scalability and automation. By leveraging the safety of Rust, the flexibility of JavaScript, and the rapid scripting capabilities of Python, this project serves as a robust framework for autonomous systems and the "Munchieverse" environment.🏗 Project ArchitectureThe repository is divided into specialized modules to maximize efficiency and maintainability:Titan_Core: The high-performance backbone built with Rust. It handles heavy-lift logic, data processing, and core engine functionalities where speed is non-negotiable.Tatiana/Scripts: A versatile collection of automation tools. Includes Lua and PowerShell for system-level tasks and JavaScript for logic flow.Tatiana_Munchieverse: The interactive frontend layer.
